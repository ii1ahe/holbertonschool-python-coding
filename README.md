# Python Coding Exercises

Python class exercises that build up a Square class step by step, plus an empty Rectangle class. They cover private fields, input checks, properties, area, and printing a shape.

## Folders

- `python-classes/`
- `python-more_classes/`

## Reading and running the exercises

Use Python 3. Read the Square files in number order to see each feature being added. The classes can be imported for testing; most files do not run a demo when launched directly.
